1

Add two new columns to the BM Groups list

In your web browser, on SharePoint
 
Last changed 26/11/2026 13:13 GMT

This is the part that is easy to miss, so it is first. The new screens need two new columns. Without them the screens show red errors.

  1. Open SharePoint and go to Site contents. Click the list called BM Groups.
  2. At the far right of the column headings, click + Add column, then choose Yes/No.
  3. Name it exactly:
    HasCustodians
    Set Default value to No, then click Save.
  4. Click + Add column again, then choose Multiple lines of text.
  5. Name it exactly:
    CustodianEmails
    Open More options and make sure Use enhanced rich text is off. Click Save.

Spell both names exactly as shown, capital letters and no spaces. Use the Copy buttons.

2

Check the Email column is not "Required"

In your web browser, on SharePoint
 
Last changed 26/11/2026 13:13 GMT

Some groups will now have members with no email address. SharePoint must allow that.

  1. Go back to Site contents and open the list BM Memberships.
  2. Click the heading of the Email column, then Column settings, then Edit.
  3. Open More options. Make sure Require that this column contains information is set to No.
  4. Click Save. If it was already No, just click Cancel.

Refresh the BM Groups data source in Power Apps Studio

In Power Apps Studio (the editor for the app)
 
Last changed 26/11/2026 13:13 GMT

Studio does not notice new columns by itself. You have to tell it.

  1. Open the app in Power Apps Studio for editing.
  2. On the far left, click the Data icon (it looks like a small database).
  3. Find BM Groups, click the three dots next to it, then click Refresh.
  4. Wait for it to finish. You should now see HasCustodians and CustodianEmails if you expand the list.

LoadCache(): Boolean = {
    Set(varLoading, true);
    Set(varCacheReady, false);
    IfError(
        Concurrent(
            ClearCollect(colMaintainers, 'BM Maintainers'),
            ClearCollect(colGroups, AddColumns(Sort('BM Groups', SortOrder, SortOrder.Ascending), Ticked, false)),
            ClearCollect(colHistoryView, Filter('BM History', false)),
            ClearCollect(colMemPart0, Filter('BM Memberships', false)),
            ClearCollect(colMemPart1, Filter('BM Memberships', false)),
            ClearCollect(colMemPart2, Filter('BM Memberships', false)),
            ClearCollect(colMemPart3, Filter('BM Memberships', false))
        );
        Concurrent(
            ForAll(Filter(colGroups, Mod(ID, 4) = 0) As g, Collect(colMemPart0, Filter('BM Memberships', GroupName = g.Title))),
            ForAll(Filter(colGroups, Mod(ID, 4) = 1) As g, Collect(colMemPart1, Filter('BM Memberships', GroupName = g.Title))),
            ForAll(Filter(colGroups, Mod(ID, 4) = 2) As g, Collect(colMemPart2, Filter('BM Memberships', GroupName = g.Title))),
            ForAll(Filter(colGroups, Mod(ID, 4) = 3) As g, Collect(colMemPart3, Filter('BM Memberships', GroupName = g.Title)))
        );
        ClearCollect(colMemberships, colMemPart0, colMemPart1, colMemPart2, colMemPart3);
        Set(varIsMaintainer, CountRows(Filter(colMaintainers, Lower(Email) = varMyEmail)) > 0);
        Set(varLastMembershipRefresh, Now());
        Set(varCacheReady, true);
        Set(varLoading, false);
        true,
        Notify("Could not finish loading Branch Contact Groups data. Check your connection, then press Refresh.", NotificationType.Error);
        Set(varCacheReady, true);
        Set(varLoading, false);
        false
    )
};

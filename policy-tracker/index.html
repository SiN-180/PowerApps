CleanDocumentUrl(RawUrl: Text): Text = With(
    {_trimmed: Trim(RawUrl)},
    With(
        {
            _cleaned:
                Left(
                    _trimmed,
                    Min(
                        If(Find("&action", _trimmed) > 0, Find("&action", _trimmed) - 1, Len(_trimmed)),
                        If(Find("&clickparams", _trimmed) > 0, Find("&clickparams", _trimmed) - 1, Len(_trimmed)),
                        If(Find("&CID=", _trimmed) > 0, Find("&CID=", _trimmed) - 1, Len(_trimmed)),
                        If(Find("&wdLOR", _trimmed) > 0, Find("&wdLOR", _trimmed) - 1, Len(_trimmed))
                    )
                )
        },
        With(
            {_idPos: Find("id=%2F", _cleaned)},
            If(
                Find("/Forms/AllItems.aspx?", _cleaned) > 0 && _idPos > 0,
                With(
                    {_afterId: Mid(_cleaned, _idPos + 3, Len(_cleaned))},
                    Left(_cleaned, Find("/", _cleaned, 9) - 1) &
                    Substitute(
                        Substitute(
                            Substitute(
                                Substitute(
                                    Left(_afterId, If(Find("&", _afterId) > 0, Find("&", _afterId) - 1, Len(_afterId))),
                                    "%2F", "/"
                                ),
                                "%2E", "."
                            ),
                            "%2D", "-"
                        ),
                        "%5F", "_"
                    )
                ),
                _cleaned
            )
        )
    )

What changed on this screen:
  • In Pick a Thursday, stand-down Thursdays are greyed out, tagged STAND DOWN with your reason, and cannot be chosen. Tapping one tells the person why.
  • If an item's date is already inside a stand-down, a red note appears under the date field, and Save, Save & Close and the Add Document Link buttons refuse until it is moved.
  • High Priority does not override a stand-down. It is a hard lock.
  • In the Duplicate dialog, stand-down Thursdays are simply left out of the list.
  • A new item no longer starts on a stand-down Thursday. It starts on the first Thursday that is open.
  • Newsletter Title and Audience are now required. Save, Save & Close and Add Document Link are greyed out until both are filled in, and an amber banner under the top bar says which one is missing. Items ticked External consultation required or Published are exempt.

Setting a real stand-down (day to day)
  1. Open the PolicyTracker-StandDownPeriods list and add a row: Title (the reason), StartDate, EndDate, Active Yes.
  2. Every Thursday from StartDate to EndDate, both included, is locked. It takes effect the next time someone opens an item or starts the app. Someone who already has an item open will not see it until they reopen it.
  3. To lift it early, set Active to No or delete the row. Periods whose EndDate has passed are ignored automatically.

Things to know. Items already booked inside a new stand-down are not moved or flagged. If someone opens one, the red note appears and they must pick another Thursday to save. Only dates from today onwards are blocked, so old items in the past are never affected. You can have as many periods as you like. If the list cannot be read, the app shows a warning and carries on without the stand-down.

If Studio shows red after pasting. A red mark on PolicyTracker-StandDownPeriods means the list was not added as a data source. A red mark on Active, Title, StartDate or EndDate means a column name differs from the table in step 1.
